# Segregacion-de-interfaz  
¿Cómo se implementa?  

Se crean clases padres con sus respectivas clases hija

Aparte de la clase padre "principal" que define los atributos basicos, se crean otras clases que tambien serán padres pero que se utilizan para acciones propias de la clase hija  

Se crean clases hijas que heredan de clases especificas, no de una general (De la cual podría surgir el riesgo de dejar métodos sin utiizar)
